# thegreatfilter.me 🌌

> *"Where is everybody?"* — Enrico Fermi

A demonstrative, interactive web exploration of **The Great Filter** hypothesis and the **Fermi Paradox**, deployed on GitHub Pages at [thegreatfilter.me](https://thegreatfilter.me).

---

## 🛰️ Features

- **Interactive Cosmic Canvas**: Lightweight, performant particle starfield with parallax responsive to cursor navigation.
- **The 9 Evolutionary Steps Explorer**: An interactive breakdown of Robin Hanson's nine critical milestones from prebiotic chemistry to interstellar colonization, with a real-time slider to position where the Filter might lie and assess its existential implications.
- **The Great Filter Probability Engine**: An interactive calculator pairing the Drake Equation with civilizational bottleneck survival rates ($S_{\text{filter}}$) featuring live updates, presets (Hanson, Sagan, Rare Earth), and philosophical interpretations.
- **The Great Dichotomy**: In-depth analysis comparing whether the barrier is behind us (Rare Earth / miracle of life) or ahead of us (existential technological risks like AGI, synthetic biology, and runaway destruction).
- **Alternative Hypotheses**: Detailed perspectives including Liu Cixin's *Dark Forest*, Nick Bostrom's *No News is Good News*, John Ball's *Zoo Hypothesis*, and the *Simulation Boundary*.
- **Modern Responsive Design**: Pure semantic HTML5, CSS3 with glassmorphism and custom properties, and vanilla ES6+ JavaScript—zero build steps, zero bloated dependencies, 100% fast and accessible.

---

## 🛠️ Tech Stack & Setup

- **HTML5 / CSS3 / Vanilla JavaScript**
- **Hosting**: GitHub Pages
- **Custom Domain**: `thegreatfilter.me` (configured via `CNAME`)

### Local Testing

You can run a local test server using Python:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080` in your web browser.
